# Alzikrayat

## Project Name

**Alzikrayat – Photo Sharing Web Application**

## A Simple Description

Alzikrayat is a PHP-based photo sharing web application that allows users to register, log in, upload and manage photos, view photo details, and add comments.

## Technologies

* PHP
* MySQL
* HTML5
* CSS3
* JavaScript
* Bootstrap
* XAMPP / Apache

## How to Run

1. Install and open **XAMPP**.
2. Start **Apache** and **MySQL**.
3. Place the project folder inside the XAMPP `htdocs` directory.
4. Open **phpMyAdmin** and create the project database.
5. Import the project's database/SQL file if provided.
6. Check the database connection settings in the project configuration.
7. Open the application in a web browser.

Example:

`http://localhost/alzikrayat_php/`
